# Technical Documentation

The project source code is located in the `prj_smart_style/` directory.

Additional project documentation is available in the repository root:

| File                                             | Description                                                                                                                                                                  |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Software Requirements Specification (SRS).docx` | Complete Software Requirements Specification, including project scope, functional and non-functional requirements, use cases, UML diagrams, database design, and UI mockups. |
| `InstallationGuide.md`                           | Step-by-step instructions for installing, configuring, and running the Flutter application.                                                                                  |
| `Desviations.md`                                 | Summary of the differences between the final implementation and the original PRJ566 proposal.                                                                                |
| `testAccounts.md`                                | Test credentials required to access the application and external services.                                                                                                   |
